# A/B-тест экрана активации

Учебный разбор эксперимента: 24 000 пользователей, два варианта экрана,
события воронки и результат за семь суток. Данные синтетические, генератор включён.
Это не результаты эксперимента реального банка.

## Результат

| Метрика | A | B |
|---|---:|---:|
| Назначено пользователей | 11 976 | 12 024 |
| Активировались за 7 суток | 2 670 | 2 990 |
| Конверсия | 22,29% | 24,87% |
| Пользователи с ошибками приложения | 3,23% | 3,39% |

Разница основной метрики — **+2,57 п.п.**, относительный рост — **11,54%**.
95% ДИ разницы: **[+1,50; +3,65] п.п.**, двусторонний p-value — **0,00000268**.
SRM не обнаружен: p=0,757. При плановом MDE 2 п.п. требовалось по 7 157 пользователей;
в обеих группах их больше.

![Результаты](reports/metrics.png)

Для ошибок приложения разница +0,16 п.п. Верхняя односторонняя 95% граница — **+0,54 п.п.**,
ниже допустимого ухудшения +1 п.п. По заданному правилу вариант B проходит проверку.
Вывод относится только к учебному сценарию; переносить величину эффекта на настоящий продукт нельзя.

## Обработка

- Единица анализа — назначенный пользователь, включая пользователей без активации.
- Дата среза — 22 августа 2026, 23:59:59 UTC. У каждого есть полные семь суток.
- Из 66 150 событий удалены 655 точных повторов. Метрики считаются по пользователям.
- Событие ровно через семь суток включается, позднее — не включается.
- Этапы воронки и платформы используются как описательные срезы.

Расчёт: SQL-витрина на уровне пользователя, z-тест двух долей,
интервал разницы долей и односторонняя граница ограничивающей метрики.
План и правило решения — [experiment.md](experiment.md).

## Запуск

Python 3.11+. Данные уже включены, повторная генерация для запуска не нужна.

```text
python -m pip install -r requirements.txt
python analysis.py
python -m unittest discover -s tests -v
```

На Windows вместо `python` можно использовать `py`.
`analysis.ipynb` — разбор с результатами, `reports/statistics.json` — точные значения.
`generate_data.py` воспроизводит источник с фиксированным seed.
Варианты, даты и события заданы симуляцией; регистрация реального A/B-теста не заявляется.
